# Space Shuttle 
The tournament manager for TETR.IO Amateur Weeklies.

> [!IMPORTANT]
> it is highly recommended to use a virtual environment (venv for short). you can create one with `python3 -m venv ./venv` and activate it with `source venv/bin/activate` (on linux). read more [here](https://docs.python.org/3/library/venv.html)

```bash
pip install
```
and
```bash
python3 bot.py
```
